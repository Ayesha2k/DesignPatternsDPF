# 🚀 Design Patterns & Frameworks (TU Dresden)

Welcome to my code for the **Design Patterns and Frameworks** Master's course at TU Dresden! 

This isn't just a place for boring definitions. This repo is a hands-on journey from rigid, static code to highly dynamic, enterprise-grade architectures. We are taking the legendary "Gang of Four" patterns off the bookshelf and putting them to work.

## 🗺️ The Journey
We are building the foundations first, learning how to separate things that change from things that stay the same. Along the way, we will tackle the official course exercises, bridging the gap between beginner pattern implementations and complex, multi-dimensional software frameworks.

### 🏗️ Repo Structure
* 🧪 **`/patterns`**: The Sandbox. This is where I practice the raw, isolated design patterns (Template Method, Objectifier, Strategy, Bridge, etc.) to understand their mechanics before using them in the wild.
* 🎓 **`/exercises`**: The Arena. The official TU Dresden exercise sheets (Sheet 1, Sheet 2, etc.) where multiple patterns are combined to solve massive architectural challenges like file systems, sensor networks, and abstract syntax trees.

## 🎯 Learning Goals
* Break free from the "inheritance lock-in" and master dynamic object delegation.
* Build faceted objects, layered frameworks, and multimethods.
* Write code that doesn't just work today, but is explicitly designed to be extended tomorrow.

Let's build some beautiful architectures! ☕💻
